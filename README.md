## Hướng dẫn kích hoạt GitHub Pages
1. Tạo repository tên `privacy` (chế độ **Public**).
2. Giải nén toàn bộ các tệp trong gói `.zip` này và tải lên thư mục gốc của repo `privacy`.
3. Vào **Settings > Pages**, tại mục **Branch** chọn `main` và thư mục `/ (root)`, nhấn **Save**.
4. Dán đường dẫn của **từng trang con tương ứng** vào Google Play Console và bên trong mã nguồn ứng dụng Android.
